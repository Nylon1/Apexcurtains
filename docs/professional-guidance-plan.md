# Professional guidance audit and implementation plan

18 October 2026. Scope: the Professionals menu and its existing public destinations, plus the linked project-information checklist. Retain all URLs and working enquiry/workspace routes.

## Audit

- Four role pages use the same three-card / two-list template. They name relevant topics but rarely explain the decisions, required evidence or consequences. Contextual links are sparse.
- The resources page is a short directory. The checklist is useful but uses decorative boxes rather than usable checkboxes and lacks guidance on revisions, assumptions and responsibility.
- The project review is a contact pathway, not an upload form. Explain what an initial review can establish and what remains subject to survey; retain contact and telephone destinations.
- The commercial page contains genuine Manchester Airport project material and a PDF, but repeats sector/service lists. Preserve the project evidence, service scope and enquiry routes while developing substantive specification and site guidance. Add its missing explicit canonical; use absolute titles to avoid repeated brand suffixes.
- The workspace menu correctly points to the authorised-user login. Authentication and project records are operational features, not public SEO pages; leave them untouched and link to login where useful.

## Information architecture

Architects: curtain envelope, recess/structure, shaped operation, drawing coordination, access and changes. Interior designers: room brief, fabric/lining/heading, scale, colour, sample approval and installation. Developers: repeatable design versus plot-specific measurement, specification options, release gates and handover. Contractors: substrate evidence, setting out, access/logistics, readiness and responsibility.

Resources: a decision-led reference library with clear links to existing specialist guides. Checklist: interactive, printable preparation aid; checked boxes do not constitute technical approval. Review: initial inputs, likely next steps, boundaries and existing contact routes. Commercial: retain Manchester Airport evidence and download; explain package interfaces, track/textile suitability, light control, site documentation, operational access and handover. Hub: connect audiences, decision stages, real evidence and workspace access.

## Components and evidence

Reuse the server-rendered SpecialistGuidePage with an opt-in professional navigation, breadcrumb and enquiry treatment. Keep existing consumer guides unchanged. Add original explanatory coordination diagrams, real existing installation photos, accessible native disclosures/checklists and contextual links. Avoid additional libraries or generalised service guarantees. Photos demonstrate visible installed results, not concealed fixings, track models or unrecorded project roles.

Technical references checked: Forest KS official product documentation and HSE tower guidance; link to existing detailed Apex guides as the main technical reference rather than duplicating load tables. Do not claim all slopes traverse, standard KS is motorised, perfect blackout, universal recess dimensions or project compliance from a generic guide. Performance/test evidence is specification-specific.
